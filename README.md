# MERN Real-Time Alarm Notification System

A real-time alarm notification system built using MERN Stack and Socket.IO.

## Features
- Real-time notifications
- Latest 10 alarms display
- MongoDB integration
- Express APIs
- React frontend
- Socket.IO live updates
- Bell icon notification UI

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- Socket.IO

## How It Works
Whenever a new alarm is inserted into MongoDB, the backend emits a Socket.IO event and the React frontend updates notifications instantly without page refresh.
